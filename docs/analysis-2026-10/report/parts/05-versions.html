The minimal loop, end to end

How the editor uses it

The commands belong to one skill, /claim-tagger. Rarely used: setup, draft-rules (one tag at a time) and rollback. Tags are judged in groups (cache groups), so a rule change re-judges only its group.

Safety checks kept, with one editor

Key: Dn is a decision of the product owner.

CheckKept?Why
AllowlistKeepA code constant intersected with the config; updates only.
Read-back, drift, pauseKeepHard rules 6 and 7; drift only for tags with rules (D23).
Protected ids and probeKeepProtected tables answer "not found" or "forbidden"; the mirror shows its two write columns.
Guard hookSimplifyDenies every connector page write; structure comes only from the setup builder.
Gate evidenceSimplifyA promote record, a PASS card that is no rehearsal, fingerprints matching the candidate, the exact text.
Promote lockMergeOne file with a phase instead of two.
Trust breakerWarn onlyA pause would catch the editor's own clicks.
Plan arming, batches, rehearsal, planted demosDropThey guarded a write path that is gone.

Defence in depth goes down to the allowlist, the deny rule on the runs folder, the guard hook and the slimmer gate evidence. That fits one editor; revisit it with more editors or unattended runs.
