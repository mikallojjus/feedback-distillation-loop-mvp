The loop in one picture

The judge, a model call, reads each claim against the rulebook; unsure answers go to the queue for the editor; decisions that blame a rule become a lesson, which the gate tests against every earlier decision. One skill, /claim-tagger, runs it all.

What the trial showed. On {{count:trial.claims}} claims the gate rejected the first lesson {{count:trial.gateAttempts}} times: each wording flipped an earlier decision on another tag (interference). The machinery around the loop is far heavier than one editor needs.
