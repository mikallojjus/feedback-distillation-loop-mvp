Talking to Claude

  • Claude can't explain a tagmoderate

    During a skill run Claude only runs scripts and reads no run records, so "why claim 12?" gets the Agent reasons line at most.

  • Thin reports, relayed word for wordmoderate

    "None of the drafts passed the checks", and nobody may say which check.

  • "Ask the engineer" dead endsmoderate

    Many refusals end with "ask the engineer to look at the message", even when the editor could fix it.

  • A stuck decide run blocks the next one for 2 hoursmoderate

    The refusal says "ask the engineer". decide check would close it, but the refusal doesn't say so.

  • A note-only decision quietly means Does not applymoderateFound in the code check

    It leaves Verified tags empty and sets Reviewed, so the agent's tag counts as rejected. The draft says "unchanged" and nothing warns.

  • One report per answermoderate

    "Tag, then distill, then show me what waits" works, but Claude can relay only one report at the end.

  • One changed claim refuses the whole batchminor

    If one claim changed in Notion after Claude read it, all 10 decisions are refused: re-read and OK again.

  • The same checklist after every Notion reportminor

    The guide's fixed 5-line checklist comes every time, with no way to turn it off.

  • Claude can only set Reviewedminor

    It can't put a claim back to To review, and even trivial batches need a draft and an OK.

  • A replaced decide run is never read backminorFound in the code check

    When a new decide replaces a stale run, the hint for checking the old one is printed for Claude only, and the skill never acts on it.

Changing the rulebook

  • Editing your own rulebook stops everythingmajor

    Any edit to the judged tag's When to use, Description, Example Claims or Counterpart stops tag, status, decide and distill until it is undone.

  • No direct way to start a rule changemajor

    A change starts only when distill finds 2 or more decided claims pointing at one rule. Claude can't write one for you, and a row typed by hand isn't supported.

  • Only an existing numbered rule can changemajor

    There's no way to add a rule 6, remove or merge rules, or edit the text around them.

  • The safety check can't be overruled, and its examples are out of reachmajor

    A FAIL always wins. The 11 example claims sit in a frozen file only the engineer changes: 5 are nowhere in Notion, and editing the other 6 in the Rulebook counts as a forbidden edit.

  • Editor wording means retyping the whole rulemoderate

    To change one word you paste the full rule. After a FAIL you copy the report's suggested text into Notion by hand.

  • Only the engineer can make a tag judgedmoderate

    Rules written for Wordy judge nothing until the engineer edits the config.

  • Drafts dropped without a visible reasonminor

    A draft that repeats 8 words of a claim is dropped. You see only "none of the drafts passed the checks".

  • A withdrawn row means reject and redraftminor

    When you re-read a supporting claim as an agent slip, you must reject the change yourself and run distill again.

  • One change at a timeminor

    One open change per rule, at most 3 drafts per run, and promote needs a title when two changes are approved.

Working in Notion

  • The views hide what you decide onmoderate

    The handover says to sort All claims by Agent confidence, a column it hides. Your queue shows neither confidence nor the Geo link. On a To review claim the agent's answer appears nowhere.

  • Lessons waiting hides what you act onmoderate

    Editor wording, Safety check result, Tag, Rule and Supporting rows aren't shown, and finished changes leave the view.

  • Re-tick the agent's tags you agree withminor

    A judged tag left out of Verified tags counts as Does not apply, even when the agent had it.

  • Notes need exact syntaxminor

    Each line should start "Tag:", and a reason word only counts with its full stop. The practice page's own examples skip the prefix.

  • Some claims have no way inminor

    The hub doesn't link Agent disagreed, and claims the agent could not read have no view.

  • Hub clutterminor

    Tag decisions (17 columns, "never edit here") and the archive page sit on the hub you work from.

  • Stale status, cut reasonsminor

    Agent status still says Waits for you after you decide, until the next tag run, and Agent reasons are cut at 40 words.

  • After a review, the agent's own answer leaves ClaimsminorFound in the code check

    The next tag run overwrites Agent tags with your tags; only the hidden ledger keeps what the agent proposed.

Hard rules and security

  • Claude can't do rule-owner actions, even when you askmoderate

    "Approve it", "use that wording" and "untick Paused" are refused. You set each one in Notion.

  • No unpause commandminor

    You untick Paused in Notion. A pause file on disk needs the engineer.

  • Claude can't add a view or column for youminor

    "Add a By Geo Space view" is refused. You can still add it by hand.

  • Nothing is ever deletedminor

    Rejected changes and old practice pages pile up.

  • A different model stops the runminor

    If another model answers, tag, distill or promote stops with "ask the engineer". The same command resumes later.

  • Only the Claims table trains the rulebookminor

    Work in Claims to review or the other real tables never reaches the rulebook.
